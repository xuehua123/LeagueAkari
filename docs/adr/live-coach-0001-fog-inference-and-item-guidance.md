# ADR-0001：迷雾推断与装备购买指导进入必做范围

- 状态：已批准
- 日期：2026-08-25
- 决策人：项目负责人
- 替代内容：P0-D03 的“仅直接空间事实”边界，以及旧版一期/二期中“不推断迷雾、不做装备购买指导”的范围限制

## 决策

1. 第一期必须实现基于当前小地图、last-seen、移动趋势、地图可达路径和允许对局状态的不可见敌人概率区域、候选路线、到达时间范围与意图预测。
2. 第一期必须实现基于英雄、位置、金币、已有装备、阵容、局势和当前补丁装备数据的购买指导。
3. 直接观测与预测分层保存和展示。预测必须携带证据、置信度、模型/规则版本、生成时间、有效时间和撤销原因，不能伪装成当前直接看见。
4. 装备功能只提供信息、语音、字幕和备选购买方案；自动购买、键鼠输入、商店操作和其他游戏自动控制仍为永久红线。

## 兼容与迁移

- 增加 `fog-inference` 与 `item-guidance` 类型、状态、设置、能力 ID、IPC 和测试资产；
- 旧 observation/evidence 保持兼容，新增预测 evidence source，不覆盖原始小地图 observation；
- 旧设置缺少新字段时使用文档规定默认值；
- 旧回放缺少所需字段时对应预测或装备规则明确显示不可用，不伪造结果。

## 验证要求

- 迷雾推断必须使用独立回放集报告区域、路线、意图、概率校准、覆盖率和撤销延迟；
- 装备推荐必须在每个支持补丁验证价格、合成路径、模式可用性、唯一限制和装备栏容量；
- Electron 端到端测试验证预测标识、置信度、设置开关、TTS 措辞、跨局清理和不触发自动输入；
- 生产构建、Windows 实机和打包 smoke 全部通过后方可标记完成。

## 回滚

两个能力使用独立 capability ID。质量或外部启用条件不满足时分别关闭正式输出并回退到直接观测、基础提醒和静态装备信息，不删除实现与离线回归能力。
