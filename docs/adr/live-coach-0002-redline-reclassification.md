# ADR-0002：永久红线重新分类

- 状态：已批准
- 日期：2026-08-25
- 决策人：项目负责人
- 替代内容：旧版文档中按功能类别永久排除实时推断、购买指导、微操、计时、通信、持续收音、多模态和主动指挥的范围限制

## 背景

旧版范围把三类不同事项混在“红线”中：功能本身、对外启用条件和未经授权的实现手段。这会让程序员误以为未完成审核、需要更高准确率或当前阶段暂不启用的功能都禁止编码，与“先完整开发和自用测试，审核只控制外部开关”的项目决定冲突。

官方产品已经存在装备推荐、配装、连招和对线提示等相近能力。它们证明这些产品类别不能仅凭名称判为永久技术红线，但不等于 League Akari 已自动取得对外发布授权。Riot 当前开发者政策对本局未知信息、替玩家决策和不公平优势仍有限制，因此这些能力必须使用独立外部 capability 和审核证据。

## 决策

永久红线只保留以下未经授权的实现或数据行为：

1. 游戏进程内存读写、DLL/Hook/驱动注入、封包拦截、协议篡改或流量解密；
2. 通过键鼠模拟、输入注入、脚本或机器人替玩家执行移动、施法、购买或点击；
3. 绕过、隐藏或规避 Vanguard/反作弊，或要求用户关闭安全保护；
4. 未经合法依据或必要授权采集、保存、上传、识别、长期画像或公开他人的语音、身份和私人通信；
5. 窃取、复用、转售或绕过授权获取账号凭据、密钥、token 与受保护非公开数据。

如果未来出现正式 SDK、公开自动化接口或书面授权，必须新增 ADR 说明接口、权限、地区、测试和回滚后，才能使用此前被禁止的技术路径。

以下功能全部改为必做，不再属于永久红线：

| 能力                                             | 阶段  | 开发要求                            | 外部启用条件                            |
| ------------------------------------------------ | ----- | ----------------------------------- | --------------------------------------- |
| 装备购买指导与备选出装                           | P1    | 必做，不自动购买                    | 装备数据与输出类别 capability           |
| 迷雾位置、路线、到达和意图预测                   | P1    | 必做，观测/预测分层                 | 模式、地区、预测输出 capability         |
| 技能加点、连招、补刀、走位、对线和团战站位       | P1–P3 | 基础、条件式、逐帧分阶段必做        | 画面、模式和输出 capability             |
| 技能、召唤师技能、野怪、眼位和资源计时           | P1–P2 | 按来源标注，未知时降级              | 数据来源与计时 capability               |
| Ping、快捷喊话、聊天摘要和沟通建议               | P1–P2 | 建议、确认发送和获准接口分层        | 接口、用户授权与频率 capability         |
| LLM 实时/离线问答和游戏知识对话                  | P3    | 必做，结构化证据与输出校验          | Provider、地区、成本与 AI capability    |
| 唤醒词、常开麦和授权音频分析                     | P3    | 必做，分项授权、持续指示、立即撤回  | 音频来源、参与者、地区和隐私 capability |
| 完整画面多模态、逐帧微操和主动 shot calling      | P3    | 必做，证据、置信度、首选/备选与撤销 | 采集、模式、地区和输出 capability       |
| 经权利人授权的音色、训练效果统计和排行榜         | P3    | 必做，授权证明、样本量与可删除      | 音色权利、隐私与公开展示 capability     |
| ARAM、斗魂竞技场、轮换模式、观战和合法跨地区增强 | P3    | 独立数据集、规则和降级              | 地图、端点、地区与授权 capability       |

## 产品与质量要求

- 产品可以突出一个当前首选并保留备选；禁止的是无证据的保证和未经授权的自动执行，不是建议排序本身；
- 战斗胜算、敌人意图和路线可以估计，但必须输出概率、置信度、证据和失效条件；
- 质量不足会关闭正式输出并继续内部修复，不会把功能重新标成红线；
- 审核未完成或失败只关闭对应外部 capability，不删除实现、测试、数据集或内部诊断。

## 兼容与迁移

- 更新所有产品、技术、工程和 Checklist 文档中的旧排除语句；
- 保留现有 capability 快照与 Gate A/B，新增能力使用更细粒度 ID；
- 旧配置不存在新开关时默认关闭高敏感采集和外部公开，不影响内部构建显式启用；
- 已有录像、事件与设置 schema 采用向后兼容的可选字段迁移。

## 验证与回滚

- 用文档扫描阻止旧版“功能类别永久禁止”措辞重新出现；
- 每项能力独立验证数据来源、性能、准确率、授权、外部开关和停止线；
- 任一能力出错只关闭对应 capability，不关闭无关能力；
- 发现未经授权的进程、输入、反作弊或他人数据行为时立即停止相关路径、保全证据并回滚。
